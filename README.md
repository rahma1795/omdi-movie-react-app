# omdi-movie-react-app
omdi movie list

## Features
- Movie search
- Infinite scroll (without plugin)
- Movie detail page
- Poster popup modal
- Redux state management
- Unit testing
- Autocomplete search

## Tech Stack
- React
- Redux Toolkit
- Axios
- Jest + React Testing Library

## Installation
```bash
git clone <your-repo-url>
cd omdi-movie-react-app
npm install
npm start
