# omdi-movie-react-app
A starter project for building omdb movie application with ReactJs. This project includes routing and API integration with Axios.

## Installation
1. **Clone the repository:**

    ```bash
    git clone <repository-url>
    cd omdi-movie-react-app
    ```

2. **Install dependencies:**
    ```
    npm install

    ```

## Scripts
  - **dev: Start the development server with ReactJs version 19.**
    ```
      npm run start
    ```

  - **unit test: unit testing the project.**
    ```
      npm run test 
      or
      npm run coverage
    ```
